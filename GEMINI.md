# Agent Guidelines

## Permissions & Autonomy
- **Full Autonomous Permission**: The user has granted full permission to perform all necessary actions (installing packages, running builds, creating/modifying files, configuring environments, running scripts).
- **Never Ask for Permission**: Do not pause, hesitate, or prompt the user in chat asking for permission or confirmation before executing required operations.
- Always proceed directly with the solution and complete tasks end-to-end.
